# Number Guessing Game

A simple number guessing game written in Python. The computer picks a random number between 1 and 100, and you try to guess it. After each guess, you get a hint to guess bigger or smaller. When you guess correctly, the program tells you how many attempts it took.

## How It Works

1. The program generates a random number between 1 and 100.
2. You enter your guess.
3. If your guess is wrong, you get a hint:
   - "Guess Bigger"
   - "Guess Smaller"
4. When you guess correctly, the program shows the total number of attempts.
